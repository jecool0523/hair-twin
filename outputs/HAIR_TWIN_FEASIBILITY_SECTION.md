# 헤어트윈 사업계획서 실현 가능성 작성안

## 1. 작성 방향

실현 가능성 파트의 핵심 목적은 헤어트윈이 단순 아이디어가 아니라 이미 작동하는 MVP, 배포된 데모, 단계별 기술 고도화 계획을 갖춘 실행 가능한 사업임을 설득하는 것임.

따라서 문단 구조는 다음 순서로 구성하는 것이 효과적임.

1. 현재 구현된 MVP가 있음을 먼저 제시함.
2. MVP가 실제 미용실 상담 흐름을 얼마나 반영하는지 설명함.
3. 핵심 기술을 처음부터 자체 개발하지 않고 외부 이미지 생성 API와 웹 기술을 활용해 빠르게 검증하는 현실적 전략을 강조함.
4. 고객 사진, API 키, 저장 데이터 등 민감 요소를 MVP 단계에서도 분리해 관리하고 있음을 설명함.
5. 향후 자동 품질 검수, 고객 기록, 결제, 매직 미러 하드웨어로 확장할 수 있는 구조임을 제시함.
6. 팀이 이미 기획, 개발, 배포, 검증을 수행했으므로 앞으로도 실행할 수 있다는 근거로 마무리함.

## 2. 실현 가능성 핵심 근거

### 2.1 작동 가능한 MVP 보유

- React와 Vite 기반의 웹 MVP를 구현했음.
- 웹캠 촬영, 이미지 업로드, 샘플 고객 이미지로 상담을 시작할 수 있음.
- 약 10개의 대표 헤어스타일 프리셋을 제공함.
- 사용자가 스타일을 선택하면 3개의 후보 이미지를 생성하는 상담 흐름을 구현함.
- 원본과 결과 이미지를 전후 비교 방식으로 확인할 수 있음.
- 결과별 품질 체크, 상태 표시, 재생성, 다운로드, 임시 저장 기능을 구현함.
- 상담 메모와 고객 별칭, 담당 디자이너 기록을 남길 수 있음.
- 상담 요약 JSON 다운로드 기능을 구현해 향후 고객 리포트와 CRM 확장의 기반을 마련함.

### 2.2 실제 배포와 시연 가능성 보유

- MVP는 로컬 개발 환경을 넘어 Vercel에 배포되어 외부에서 접속 가능한 상태임.
- GitHub 저장소에 코드가 푸시되어 버전 관리가 가능함.
- API 키가 없는 경우에도 mock preview로 상담 흐름을 시연할 수 있음.
- OpenAI API 키를 UI에서 입력해 GPT Images 기반 생성 요청을 테스트할 수 있음.
- Vercel 서버리스 API route를 추가해 배포 환경에서도 이미지 생성 요청이 동작할 수 있는 구조를 마련함.

### 2.3 기술 구현 방식의 현실성

- 초기 단계에서는 고가의 매직 미러 하드웨어를 먼저 제작하지 않음.
- PC, 태블릿, 웹캠 기반 웹앱으로 핵심 상담 가치를 먼저 검증함.
- 자체 AI 모델 개발보다 외부 이미지 생성 API를 활용해 빠르게 결과 품질과 사용자 반응을 확인함.
- 헤어스타일 변경 대상은 길이, 컬러, 볼륨, 컬, 질감으로 제한함.
- 고객의 얼굴 정체성, 표정, 피부톤, 의상, 배경은 유지하는 방향으로 프롬프트와 품질 체크 기준을 설계함.
- 결과 품질을 자동으로 완전히 판정하기 전 단계에서도 미용사가 수동으로 검토할 수 있는 체크리스트를 제공함.

### 2.4 데이터와 보안 확장 가능성

- MVP에서는 복잡한 DB를 사용하지 않고 localStorage와 세션 상태 중심으로 빠르게 검증함.
- 고객 원본 사진은 명시적 저장 동의가 있을 때만 저장하도록 UX를 구성함.
- API 키는 프론트 코드에 고정하지 않고 사용자가 UI에서 입력하거나 서버 환경변수로 전달할 수 있게 설계함.
- 향후에는 Supabase 또는 별도 백엔드를 통해 고객 동의, 상담 기록, 이미지 삭제, 권한 관리, 매장별 데이터 분리를 구현할 수 있음.
- 실제 미용실 파일럿 단계에서는 고객 사진 암호화, 저장 기간 제한, 삭제 요청 처리, 관리자 권한 분리 체계를 추가할 계획임.

### 2.5 단계별 고도화 계획

- 1단계는 현재 MVP를 활용해 상담 흐름과 사용자 반응을 검증하는 단계임.
- 2단계는 실제 미용실 또는 지인 고객을 대상으로 상담 실험을 진행해 얼굴 보존, 헤어 자연스러움, 상담 전환 효과를 측정하는 단계임.
- 3단계는 자동 품질 검수, 헤어 영역 마스크, 고객 상담 리포트, 매장별 저장 기능을 추가하는 단계임.
- 4단계는 B2B SaaS 형태로 미용실 월 구독 상품을 테스트하는 단계임.
- 5단계는 검증된 소프트웨어를 기반으로 태블릿 거치형 키트와 매직 미러형 하드웨어로 확장하는 단계임.

## 3. 사업계획서 삽입용 최종 문안

### 실현 가능성

헤어트윈은 단순한 아이디어 단계가 아니라, 현재 실제로 작동하는 웹 기반 MVP를 보유하고 있습니다. 현재 MVP는 React와 Vite 기반으로 구현되어 있으며, 고객 사진 입력, 헤어스타일 프리셋 선택, AI 후보 생성, 전후 비교, 상담 메모, 품질 체크, 결과 저장, 상담 요약 다운로드 기능을 포함하고 있습니다. 이를 통해 미용실 현장에서 고객과 미용사가 같은 화면을 보며 헤어스타일을 비교하고 상담하는 핵심 흐름을 이미 시연할 수 있습니다.

현재 MVP는 웹캠 촬영, 이미지 업로드, 샘플 고객 이미지 입력을 지원합니다. 따라서 실제 고객이 없는 데모 상황에서도 샘플 이미지로 상담 흐름을 보여줄 수 있고, 실제 파일럿 상황에서는 고객 사진을 직접 입력해 상담을 진행할 수 있습니다. 사용자는 약 10개의 대표 헤어스타일 프리셋 중 하나를 선택할 수 있으며, 선택한 스타일에 대해 3개의 후보 결과를 생성하고 비교할 수 있습니다. 이는 미용사가 하나의 결과만 보여주는 것이 아니라, 보수적인 스타일, 조금 더 표현적인 스타일, 균형 잡힌 스타일을 함께 제안하는 상담 구조로 확장 가능함을 보여줍니다.

헤어트윈의 구현 방식은 초기 창업팀이 현실적으로 실행할 수 있는 방식입니다. 최종적으로는 매직 미러형 디바이스를 지향하지만, 초기에는 고가의 하드웨어를 먼저 제작하지 않고 PC, 태블릿, 웹캠 기반 웹앱으로 핵심 가치를 검증합니다. 이 방식은 제작 비용과 개발 리스크를 낮추면서도 미용실 상담에서 가장 중요한 기능인 촬영, 스타일 선택, 결과 비교, 상담 기록을 빠르게 테스트할 수 있는 장점이 있습니다.

AI 이미지 생성 기술 역시 단계적으로 접근하고 있습니다. 초기에는 자체 모델을 처음부터 개발하는 대신 GPT Images와 같은 외부 이미지 생성 API를 활용하여 빠르게 품질을 검증합니다. 프롬프트 구조는 고객의 얼굴 정체성, 얼굴 구조, 피부톤, 표정, 의상, 배경을 유지하고, 변경 대상은 헤어스타일, 길이, 컬러, 볼륨, 질감으로 제한하도록 설계되어 있습니다. 또한 결과 이미지가 실제 미용 상담에 사용할 수 있을 만큼 자연스러운지 확인하기 위해 얼굴 동일성, 피부톤 유지, 헤어만 변경 여부, 의상과 배경 유지, 스타일 일치 여부를 수동으로 체크할 수 있는 품질 기준표를 포함하고 있습니다.

현재 MVP는 배포 가능성도 검증되어 있습니다. 개발된 웹앱은 GitHub 저장소에 푸시되어 버전 관리가 가능하고, Vercel에 배포되어 외부 접속이 가능한 상태입니다. 또한 배포 환경에서도 이미지 생성 요청을 처리할 수 있도록 Vercel 서버리스 API route를 추가했습니다. API 키가 없는 환경에서는 mock preview로 상담 흐름을 시연할 수 있고, API 키를 입력하면 GPT Images 기반 생성 요청을 테스트할 수 있습니다. 즉, 제품은 문서상 구상에 머무는 것이 아니라 실제 웹 환경에서 실행되고 검증 가능한 상태입니다.

데이터와 보안 측면에서도 MVP 단계에 맞는 기본 구조를 갖추고 있습니다. 고객 원본 사진은 명시적으로 저장 동의를 표시했을 때만 저장되도록 설계되어 있으며, 상담 메모와 결과 후보는 임시 저장 또는 브라우저 저장 수준에서 관리됩니다. API 키는 코드에 고정하지 않고 사용자가 UI에서 입력하거나 서버 환경변수로 관리할 수 있도록 분리했습니다. 향후 실제 미용실 파일럿 단계에서는 고객 사진 암호화, 저장 기간 제한, 삭제 요청 처리, 매장별 데이터 분리, 관리자 권한 관리 기능을 추가할 계획입니다.

향후 개발 계획도 단계적으로 수립되어 있습니다. 1단계에서는 현재 MVP를 기반으로 사용자 흐름과 상담 반응을 검증합니다. 2단계에서는 실제 미용실 또는 지인 고객을 대상으로 파일럿 테스트를 진행하여 얼굴 보존, 헤어 자연스러움, 상담 시간 단축, 고객 만족도 변화를 측정합니다. 3단계에서는 헤어 영역 마스크, 자동 품질 검수, 고객 상담 리포트, 매장별 저장 기능을 추가합니다. 4단계에서는 B2B SaaS 형태로 월 구독 상품을 테스트하고, 5단계에서는 검증된 소프트웨어를 기반으로 태블릿 거치형 키트와 매직 미러형 하드웨어로 확장합니다.

따라서 헤어트윈은 기술적으로도 사업적으로도 실현 가능한 창업 아이템입니다. 현재 팀은 아이템 기획, MVP 개발, AI 생성 파이프라인 설계, 품질 체크 구조, GitHub 버전 관리, Vercel 배포까지 이미 수행했습니다. 이는 팀이 단순히 아이디어를 제안하는 단계가 아니라, 실제 작동하는 제품을 만들고 개선하며 시장 검증 단계로 나아갈 수 있는 실행 역량을 갖추고 있음을 보여줍니다.

## 4. 심사위원 설득용 한 문단 요약

헤어트윈의 가장 큰 실현 가능성은 이미 작동하는 MVP가 있다는 점입니다. 현재 팀은 웹캠 촬영, 이미지 업로드, 헤어스타일 프리셋, AI 후보 생성, 전후 비교, 상담 메모, 품질 체크, 결과 저장 기능을 갖춘 웹앱을 구현했고, 이를 GitHub와 Vercel에 배포하여 실제 접속 가능한 상태로 만들었습니다. 초기에는 고가의 매직 미러 하드웨어를 제작하지 않고 태블릿과 웹캠 기반 MVP로 상담 가치를 검증하며, 외부 이미지 생성 API를 활용해 AI 품질을 빠르게 개선합니다. 이후 고객 데이터 관리, 자동 품질 검수, 매장별 상담 기록, B2B 구독 모델, 매직 미러 하드웨어로 단계적으로 확장할 계획입니다. 따라서 헤어트윈은 단순 구상이 아니라 현재 MVP와 명확한 고도화 로드맵을 바탕으로 실제 사업화가 가능한 아이템입니다.

## 5. 발표용 핵심 문장

- 이미 작동하는 MVP를 구현했고, GitHub와 Vercel 배포까지 완료했습니다.
- 초기에는 고가 하드웨어가 아니라 웹캠과 태블릿 기반 MVP로 검증합니다.
- 자체 AI 모델 개발 전 외부 이미지 생성 API를 활용해 빠르게 품질과 수요를 검증합니다.
- 고객 얼굴 보존과 헤어만 수정하는 품질 기준을 별도로 설계했습니다.
- 고객 사진 저장 동의, API 키 분리, 향후 데이터 보안 확장 계획을 갖추고 있습니다.
- MVP에서 파일럿, SaaS, 매직 미러 하드웨어로 이어지는 단계별 실행 계획이 있습니다.
